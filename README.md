# TinDog

A landing page for a fictional dating app for dogs — the standard Bootstrap 5 exercise
from *The Complete Web Development Bootcamp*.

Built in July 2022. This is the oldest code in my account.

## Stack

HTML · CSS · Bootstrap 5

## Running it

Open `index.html` in a browser.

## What it covered

Bootstrap's grid and breakpoints, component classes for navbar, cards and buttons, and
overriding framework styles with a custom stylesheet — the first time I had built a page
that held together on a phone without me fighting it.
